# 项目文件工作区

项目文件属于项目沙箱，保存文本文档与图片：文本支持 `.md`、`.txt`、`.json`、`.csv`、`.yaml`、`.yml` 和 `.toml`，图片支持 `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif` 和 `.svg`，单文件上限为 10 MiB；论文 PDF 在文献库中管理。Markdown 中的论文链接可在右侧打开详情并点击“阅读 PDF”；文件页与文献库使用同一阅读工作区。

文件页把面包屑、上传、新建目录、新建文件和刷新合成一行，不再显示重复的页面标题或展开侧栏按钮。左侧目录默认展开并通过目录接口加载子项，手动收起后的状态在刷新目录时保留，右侧保留单文件预览与编辑。点击目录改变新建和上传的目标目录，不会关闭当前文件；目录刷新保留已加载子目录的展开状态。窄屏使用“文件树／文件内容”切换。

文件树与内容区之间是可拖拽分隔条（Reka UI Splitter，支持键盘方向键与双击复位）。文件树宽度默认 256px，可在 180–400px 间调整，数值保存在全局 localStorage（`ppx-console-file-tree-width`），跨项目与刷新后生效。

图片可上传、预览、下载、删除及复制 Markdown 引用，不提供编辑器：选中图片时右侧通过后端 `/projects/{project_id}/files/preview` 内联显示（该端点带 `Content-Security-Policy: sandbox`，SVG 无法执行脚本），控制器对图片不请求文本内容。文本文件才可读取、编辑与保存。

内容区允许收缩并独立滚动。JSON 等原始文本采用软换行，不改变文件字节或缩进；Markdown 正文换行，代码块、宽表格和公式在自身区域横向滚动。编辑器采用软换行，保存的仍是输入内容。

切换文件、关闭编辑、切换项目或离开文件页时，有未保存内容会提示保存、放弃或取消。保存失败时保留草稿。关闭浏览器或重新加载页面时，浏览器会提示尚未保存的内容。

上传允许一次选多个文件，接受上述文本与图片扩展名，并在提交前刷新目标目录；同名文件逐项询问覆盖或跳过。扩展名错误、超限或单项上传失败不会阻断其他文件，结果区逐项列出成功、失败或跳过的原因。后端按真实内容校验图片（文件头、扩展名一致性与解码校验，SVG 必须静态自包含），校验失败以可定位的错误返回。

“下载原文件”适用于所有受支持文件，使用后端 `/projects/{project_id}/files/download` 返回的原始字节；“转换导出”仅针对 Markdown，保留 Markdown、Word、PDF、HTML 格式。删除仅删除所选文件或空目录；非空目录不会递归删除。

状态由文件浏览器 controller 维护，目录和文件请求各自记录所属项目及请求次序：项目切换或组件销毁后丢弃旧响应，快速点击多个文件时仅最后一次读取可以更新内容。上传、保存和删除期间禁止重复写操作。

## 验证

在项目内运行 `pnpm exec vitest run src/composables/useProjectFileBrowserController.test.ts src/api/projects.test.ts src/utils/fileTreeWidth.test.ts src/utils/projectImage.test.ts`，覆盖目录懒加载、请求竞态、草稿选择、上传冲突、单项失败、原始下载字节、图片预览 URL、空目录删除契约与文件树宽度钳制；使用 `just pre-commit` 与 `just typecheck` 完成项目检查。

视觉验证使用合成的超长单行 JSON、长链接、宽代码块、表格及公式，分别检查窄屏与桌面的亮暗主题，以及右侧抽屉打开时的宽度约束；再检查图片预览、分隔条拖拽与刷新后的宽度恢复。自动构建和单元测试不能替代实际浏览器检查。

Markdown 图片以当前文件目录为基准，根路径 `/` 相对项目根，允许项目内 `../`；越界和缺失图片显示路径提示。浏览器可显示网络图片，但转换导出前须先上传到项目，外链、缺图和越界资源会阻止转换并列出原因。DOCX/PDF 内嵌图片，WebP/GIF 转静态 PNG，SVG 以三倍源尺寸转 PNG；HTML 内嵌图片并保留 SVG。`.md` 下载保留原字节，项目 ZIP 保留相对目录。

单文件转换显示准备、转换、传输、完成或失败；转换阶段不定进度，传输阶段按响应总字节显示进度。项目 ZIP 使用独立导出面板：轮询可恢复的作业，按实际条目显示打包进度，支持取消、停止接收、刷新后再次下载及 24 小时保留。
