# 项目文件工作区

项目文件属于项目文本沙箱，支持 `.md`、`.txt`、`.json`、`.csv`、`.yaml`、`.yml` 和 `.toml`，单文件上限为 10 MiB；论文 PDF 在文献库中管理。Markdown 中的论文链接可在右侧打开详情并点击“阅读 PDF”；文件页与文献库使用同一阅读工作区。

左侧文件树在目录展开时加载子项，右侧保留单文件预览与编辑。点击目录改变新建和上传的目标目录，不会关闭当前文件；目录刷新保留已加载子目录的展开状态。窄屏使用“文件树／文件内容”切换。

内容区允许收缩并独立滚动。JSON 等原始文本采用软换行，不改变文件字节或缩进；Markdown 正文换行，代码块、宽表格和公式在自身区域横向滚动。编辑器采用软换行，保存的仍是输入内容。

切换文件、关闭编辑、切换项目或离开文件页时，有未保存内容会提示保存、放弃或取消。保存失败时保留草稿。关闭浏览器或重新加载页面时，浏览器会提示尚未保存的内容。

上传允许一次选多个文件，并在提交前刷新目标目录；同名文件逐项询问覆盖或跳过。扩展名错误、超限或单项上传失败不会阻断其他文件，结果区逐项列出成功、失败或跳过的原因。

“下载原文件”适用于所有受支持文件，使用后端 `/projects/{project_id}/files/download` 返回的原始字节；“转换导出”仅针对 Markdown，保留 Markdown、Word、PDF、HTML 格式。删除仅删除所选文件或空目录；非空目录不会递归删除。

状态由文件浏览器 controller 维护，目录和文件请求各自记录所属项目及请求次序：项目切换或组件销毁后丢弃旧响应，快速点击多个文件时仅最后一次读取可以更新内容。上传、保存和删除期间禁止重复写操作。

## 验证

在项目内运行 `pnpm exec vitest run src/composables/useProjectFileBrowserController.test.ts src/api/projects.test.ts`，覆盖目录懒加载、请求竞态、草稿选择、上传冲突、单项失败、原始下载字节和空目录删除契约；使用 `just pre-commit` 与 `just typecheck` 完成项目检查。

视觉验证使用合成的超长单行 JSON、长链接、宽代码块、表格及公式，分别检查窄屏与桌面的亮暗主题，以及右侧抽屉打开时的宽度约束。自动构建和单元测试不能替代实际浏览器检查。
